# NeuroClash – AI vs Human Cognitive Challenge 🧠⚡

## Overview

**NeuroClash** is an interactive web-based game where players compete against AI in a series of cognitive challenges. The game is designed to test reaction speed, memory, typing accuracy, and logical thinking while providing a fun Human vs AI experience.

The project was developed as a college project and showcased at **Navodaya Institute of Technology, Raichur**.


## Features

* 🤖 Human vs AI gameplay
* 🎮 Multiple cognitive challenge rounds
* ⚡ Fast and responsive interface
* 🧠 Increasing difficulty levels
* 📊 Score tracking
* 📱 Responsive design
* 🎨 Modern UI with smooth animations

## Game Modes

### 🟢 Round 1 – Reaction Tap

Test your reflexes by tapping as quickly as possible when the target appears.

### 🟡 Round 2 – Reverse Typing

Challenge your concentration by typing words in reverse before the timer runs out.

### 🔴 Round 3 – Rule Roulette

The hardest level where game rules change dynamically, requiring quick thinking and adaptability.


## AI Difficulty Levels

* 😴 **Sleepy AI** – Beginner
* 🙂 **Normal AI** – Balanced
* 😈 **Tryhard AI** – Expert

Each AI level reacts at different speeds, making every match unique and challenging.

## Installation

Clone the repository

```bash
git clone https://github.com/arfanoorain-pixel/neuroclash.git
```

Go to the project folder

```bash
cd neuroclash
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```
